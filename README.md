# 🎓 Student Performance Analysis

## 📌 Overview

This project analyzes student performance data to identify patterns and insights.

## 🛠 Tools Used

* Python
* Pandas
* Matplotlib

## 📂 Project Structure

 → Dataset (CSV file)
→ Python analysis code

## 🔍 Key Insights

* Higher attendance leads to better scores
* Study time impacts performance

## 📊 Dataset

Student dataset containing marks, attendance, and study hours.
